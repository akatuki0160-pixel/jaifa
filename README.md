# 会員番号検索システム

所属協会・氏名（姓・名）・会社名を入力すると、4項目すべてが一致した会員の会員番号を表示するシステムです。
会員データはCSVで取り込みます（4万件で取込約1秒、検索は1件1ミリ秒未満）。

元システム（`https://www.jaifa-learning.com/script/qryno/qryNo.php`）の画面・URL・入力項目を再現しています。

| 画面 | URL | 内容 |
|---|---|---|
| 入力画面 | `qryNo.php` | 所属協会・姓・名・会社名を入力 |
| 検索結果 | `qryNoExe.php` | 会員番号を表示／該当なし・複数該当の場合は本部事務局の連絡先を表示 |
| 会員データ管理 | `admin.php` | 会員CSVの取込（パスワード保護） |

## 動作環境

- PHP 8.1 以上（8.1 と 8.4 で動作確認済み）。拡張モジュール `mbstring`・`pdo_sqlite`（一般的な共有サーバーでは標準で有効）
- Apache（`.htaccess` 対応）または nginx など
- データベースサーバーは不要です（会員データは `data/members.sqlite` ファイルに保存）
- Composer 等の追加ライブラリは不要です

## 設置方法

次のどちらかで設置します。

### A. ドキュメントルートを `public/` に向ける（推奨）

プロジェクトを公開ディレクトリの外に置き、Webサーバーの公開先（またはエイリアス）を `public/` にします。
会員データ（`data/`）や設定（`config/`）はWebから一切見えません。

nginx の例（PHP-FPM）:

```nginx
location /script/qryno/ {
    alias /path/to/jaifa/public/;
    index qryNo.php;
    location ~ /\. { deny all; }
    location ~ \.php$ {
        fastcgi_pass unix:/run/php/php-fpm.sock;
        include fastcgi_params;
        fastcgi_param SCRIPT_FILENAME $request_filename;
    }
}
```

### B. フォルダごと公開ディレクトリに置く（共有サーバー向け・Apache）

このフォルダ一式を、たとえば `public_html/script/qryno/` にアップロードします。
直下の `.htaccess` がすべてのアクセスを `public/` に振り分けるため、URL は元システムと同じ
`https://（ドメイン）/script/qryno/qryNo.php` になります。

- `mod_rewrite` が必要です（ほとんどの共有サーバーで利用可）。
- `data/`・`config/`・`app/` などは各フォルダの `.htaccess` でもアクセスを拒否しています（Apache 2.4 で確認済み）。
- nginx では `.htaccess` が効かないため、必ず A の方法で設置してください。

### 共通の注意

- `data/` フォルダに PHP から書き込めるようにしてください（取込時にデータベースを作成します）。
- 4万件のCSVは 2〜4MB になります。PHP の初期設定（`upload_max_filesize = 2M`）では管理画面から取り込めないため、
  `public/.user.ini`（PHP-FPM/CGI 用）と `public/.htaccess`（Apache の mod_php 用）で上限を 32MB にしています。
  サーバーによってはコントロールパネルの php.ini 設定で変更が必要です。管理画面に現在の上限が表示されます。

## 初期設定

1. サーバーごとの設定ファイルを作ります。

   ```sh
   cp config/config.local.php.example config/config.local.php
   ```

2. 管理画面のパスワードを決め、ハッシュを作って `config/config.local.php` の `admin.password_hash` に貼り付けます。

   ```sh
   php bin/hash-password.php
   ```

   設定しない間は管理画面は無効です（コマンドでの取込は使えます）。

3. `admin.php` にログインして会員CSVを取り込みます（またはコマンドで `php bin/import.php 会員データ.csv`）。

4. `qryNo.php` で検索できることを確認します。

## 会員CSVの形式

1行目に見出し、2行目以降に会員1人を1行で入れます（管理画面から見出しだけのテンプレートをダウンロードできます）。

```csv
会員番号,所属協会,姓,名,会社名
10000001,130　東京,山田,太郎,代理店
10000002,130　東京,佐藤,花子,日本生命保険相互会社
10000004,010　札幌,髙橋,健一,ＳＯＭＰＯひまわり生命保険株式会社
```

- **文字コード**: Shift_JIS（Excel の「CSV（コンマ区切り）」）、UTF-8（BOM有無どちらも）、UTF-16 を自動判別します。タブ区切りも可。
- **見出し名**: 表記ゆれを受け付けます（例: `会員NO`、`協会`、`氏名(姓)`、`所属会社名`）。列の順序は自由で、余分な列は無視します。
  見出しの前にタイトル行などがあっても構いません（先頭10行から見出し行を探します）。受け付ける見出し名は `config/config.php` の `import.columns` で変更できます。
- **姓・名**: 「姓」「名」の列がなく「氏名」列だけの場合は、姓と名の間の空白（全角・半角）で分けて取り込みます。
- **所属協会**: `130　東京`・`130`・`東京` のどの書き方でも構いません。
- **会社名**: 検索画面の選択肢と同じ表記にしてください（全角・半角の違いは問いません）。
- **会員番号**: 文字列として扱います。Excel で編集すると先頭の「0」が消えることがあるため注意してください（桁数がばらつくと取込時に警告します）。

### 取込時のチェック

- 空欄・マスタにない所属協会や会社名などの不備がある行は、**行番号と理由を表示して取り込みません**（他の行は取り込みます）。
- 次の場合は警告します。
  - 所属協会・氏名・会社名がすべて同じで会員番号が異なる会員（検索しても番号を特定できないため）
  - 同じ会員番号が複数行にある
  - 会員番号の桁数がそろっていない
- 取込は「全件置き換え」です。新しいデータベースを作り終えてから入れ替えるので、取込中や失敗時も検索は以前のデータで動き続けます。
- 取込件数が現在の半分未満になる場合は、誤ったファイルの取込を防ぐため置き換えを止めます（「件数が減っても置き換える」を選ぶと実行）。
- 「検証のみ」を選ぶと、データを置き換えずにチェック結果だけ確認できます。
- 取込履歴（日時・結果・ファイル名・件数・実行者）は `data/logs/import.log` に記録され、管理画面に表示されます。

### コマンドでの取込

```sh
php bin/import.php 会員データ.csv            # 取り込んで置き換える
php bin/import.php 会員データ.csv --dry-run  # 検証のみ
php bin/import.php 会員データ.csv --force    # 件数が大幅に減っても置き換える
```

## 検索の仕様

- 所属協会・姓・名・会社名の **4項目すべての完全一致** で検索します（部分一致・あいまい検索はしません）。
- 入力方法の違いだけは同一とみなします: 前後の空白、全角/半角の英数字・空白、半角カタカナ、英字の大文字/小文字。
- 漢字の字体（`髙`/`高`、`﨑`/`崎` など）やひらがな/カタカナの違いは区別します（元システムと同じ。入力画面の※2の注意書きのとおり）。
- 条件に合う会員が複数いて会員番号が1つに決まらない場合は、番号を表示せず本部事務局への連絡を案内します。
- 同じ接続元から「該当なし」が続いた場合（初期設定: 10分間に30回）、総当たり対策として一時的に検索を止めます。

## 設定（`config/config.php`）

変更したい項目だけを `config/config.local.php` に書くと上書きされます。

| 項目 | 内容 |
|---|---|
| `site.back_to_input_url` | 「会員番号入力に戻る」ボタンの戻り先（空にするとボタン非表示） |
| `site.logo` / `site.logo_alt` | ロゴ画像 |
| `contact` | 該当なし時に表示する団体名・受付時間・電話番号 |
| `rate_limit.search` | 「該当なし」の回数制限（`max` を 0 にすると無効） |
| `rate_limit.admin_login` | 管理画面のログイン失敗の回数制限 |
| `import.columns` | CSVの見出し名の候補 |
| `import.shrink_guard_ratio` | 件数減少ガードの割合（初期値 0.5） |
| `admin.password_hash` | 管理画面のパスワードハッシュ |
| `admin.idle_timeout` | 管理画面の自動ログアウトまでの秒数 |
| `data_dir` | 会員データの保存先 |

入力画面の注意書き（※1〜※3）の文言は `app/views/search/form.php` にあります。

## 所属協会・会社名の選択肢（マスタ）

`config/masters.php` に、元システムと同じ54協会・24社を同じ順序で登録しています。
追加・変更した場合は、検索結果に反映するため CSV を取り込み直してください（管理画面に注意が表示されます）。

## セキュリティ

- 会員データ・設定・プログラムは Web から直接参照できません（`public/` 以外は公開しない構成＋各フォルダの `.htaccess`）。
- 検索フォーム・管理画面は CSRF トークンで保護しています。
- 結果画面はブラウザ等にキャッシュさせません。Content-Security-Policy 等のセキュリティヘッダーを送信します（JavaScript は使っていません）。
- 管理画面はパスワード（ハッシュで保存）で保護し、ログイン失敗の回数制限と一定時間での自動ログアウトがあります。
  さらに IP アドレスで制限したい場合は、Webサーバー側で `admin.php` へのアクセス元を制限してください。
- 回数制限のために記録する接続元IPは、そのままではなくハッシュ化して保存します。
- アップロードされたCSV自体はサーバーに保存しません。

## 開発・テスト

```sh
# ローカルで起動（http://localhost:8000/qryNo.php）
php bin/import.php sample/members_sample.csv
php -S localhost:8000 -t public

# テスト（組み込みサーバーを使った画面の通しテストを含む）
php tests/run.php

# 負荷確認用のダミーデータ（4万件）を作る
php bin/make-sample.php 40000 sample/members_dummy.csv          # UTF-8
php bin/make-sample.php 40000 sample/members_dummy.csv --sjis   # Shift_JIS
```

`sample/members_sample.csv` は動作確認用の架空データです（`130　東京 / 小林 大輔 / 代理店` は「複数該当」の例）。

## 元システムとの違い

- 検索結果「該当あり」の画面は元システムで確認できなかったため、既存のデザイン（青枠・結果欄のスタイル）に合わせて作成しています。
- 同じ条件の会員が複数いる場合の案内、回数制限、データ未登録時の案内を追加しています。
- ボタン類は JavaScript を使わないリンクにしています（見た目は同じ）。
- 検索エンジンに登録されないよう `noindex` を指定しています。
